# 📐 Geometry Calculator

A simple and interactive web application built with HTML, CSS, and JavaScript to perform various geometry calculations easily.

## 🚀 Live Demo
You can check out the live version of the project here: 
👉 [Live Website Link]https://ranaabdelsalamm.github.io/Geomtry-calculator/

## 🛠️ Built With
* **HTML5** - Structure of the web pages.
* **CSS3** - Styling and layout design.
* **JavaScript** - Core logic and calculation functions.

## ✨ Features
* Calculate areas and perimeters for different geometric shapes.
* Clean, responsive, and user-friendly interface.
